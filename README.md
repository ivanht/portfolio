# Projects portfolio

A static, projects-only portfolio prepared for GitHub Pages. It contains anonymized professional project summaries and descriptions of three independent projects. It omits personal contact details, employers, clients, and profile links.

## Publish with GitHub Pages

1. Create a repository in the personal GitHub account. For the account homepage, name it `<account-name>.github.io`.
2. Add the contents of this directory to the repository's root.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, then choose the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

The site has no build step or dependencies. It loads web fonts from Google Fonts; system sans-serif fonts remain as a fallback. The AI Walkers and Garage Doors repositories are private, and the page labels them accordingly.

## Content notes

Professional project scope and scale statements are drawn from the supplied CV. Side project descriptions were summarized from each repository's README or project configuration. The AI Walkers project is marked in progress as stated in its README.
