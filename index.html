02MULTI-REGION

High-throughput cloud platform

Migrated a locally hosted three-tier solution to an active-active Amazon ECS platform spanning five AWS regions. Dockerized workloads, established CI/CD pipelines, and implemented monitoring and alerting. The platform served millions of clients and billions of HTTP requests per week across Europe, the Americas, Asia-Pacific, and Africa, while substantially reducing incidents and making on-call callouts very rare.

  • AWS ECS
  • CloudFormation
  • Ansible
  • Jenkins
  • GitHub
