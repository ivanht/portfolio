EC2 to Kubernetes platform migration

Led the architecture and migration of a globally distributed platform from EC2 workloads to Amazon EKS across multiple AWS regions. Scope included containerization, orchestration, and migration of messaging, caching, CDN, object storage, and relational database components while maintaining SLA commitments.

02AUTOSCALING MIGRATION

Peak-ready ECS and database autoscaling

Replaced standalone EC2 instances that were overprovisioned year-round yet still undersized for peak periods with an autoscaling Amazon ECS platform and a database that scaled with demand. The new platform cut costs by 70%, maintained SLA commitments, and kept message delivery within a few seconds during peaks. The pending-ticket backlog fell from thousands to a handful, with no more than three tickets older than one month, while maintaining strong security standards.

  • Amazon EC2
  • Amazon ECS
  • Autoscaling
  • Database scaling
  • Messaging
  • Security
03MULTI-REGION

High-throughput cloud platform

Migrated a locally hosted three-tier solution to an active-active Amazon ECS platform spanning five AWS regions. Dockerized workloads, established CI/CD pipelines, and implemented monitoring and alerting. The platform served millions of clients and billions of HTTP requests per week across Europe, the Americas, Asia-Pacific, and Africa, while substantially reducing incidents and making on-call callouts very rare.

  • AWS ECS
  • CloudFormation
  • Ansible
  • Jenkins
  • GitHub

Standardized provisioning and delivery with infrastructure as code, configuration management, and CI/CD workflows.
